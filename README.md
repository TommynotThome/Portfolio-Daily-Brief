# portfolio-daily-brief · 美股每日战报生成器

一个**零依赖**的 Python 脚本集，把「持仓 → 决策 → 一页报告」这条链路自动化。

它不预测行情，也不推荐股票。它做的是：**把你的纪律写成代码，每天替你算一遍"现在该做什么"**，然后输出一份排好版的 HTML 报告，可以直接打印成 PDF。

> 所有金额、股数、交易记录都来自你自己填的 `portfolio.json`。仓库里**不含任何真实账户数据**，示例文件里的数字全部是虚构的。

---

## 它解决的问题

小资金做美股的真正难点不是选股，是**每次下跌时的判断成本**：

- 跌 5% 该不该加？跌 15% 呢？
- 现金留多少才不算空转？
- 想买个股，怎么判断"这一笔比加宽基更划算"？
- 今天涨了 2%，是趋势还是噪音？

这个项目把这些问题的答案固化成规则，每天用一份报告给出**唯一的动作**（通常是"零"）。

## 快速开始

```bash
git clone <this-repo>
cd portfolio-daily-brief

cp portfolio.example.json portfolio.json   # 改成你自己的持仓与现金
python gen_daily.py                        # 抓行情 → daily_data.json + chart.svg
python build_daily_html.py                 # 生成 daily-brief.html
```

打开 `daily-brief.html` 即可。浏览器里 `Ctrl+P` 可直接打印成 PDF。

**依赖**：Python 3.9+，**只用标准库**（`urllib` / `json` / `re` / `datetime`）。不需要 pip install。

## 配置：`portfolio.json`

整个项目只有这一个数据入口。改完重跑两个脚本就生效。

| 字段 | 说明 |
|---|---|
| `positions` | 当前持仓股数，如 `{"SPYM": 30, "QQQM": 1.94, "VXUS": 2.2}`。**不支持碎股的标的要填整数** |
| `cash` | 当前现金（美元） |
| `positions_prev` / `cash_prev` | **上一个交易日收盘**时的持仓与现金，用来算当日涨跌。没有成交时与上面相同 |
| `deposit_today` | 今天到账的入金，没有填 `0`。**填错会把入金说成收益** |
| `today_trades` | 今天的成交列表，没有就留 `[]` |
| `fee_per_trade` | 每笔平台费（本项目的例子用 $1.88/笔、0 佣金） |
| `closed_positions` | 已清仓标的，用于复盘段落。`stop` / `take` 是当初设的止损止盈线 |
| `rebalance` | 最近一次再平衡的成交明细，用于计算"执行成本" |
| `watchlist` / `benchmarks` | 关注的个股与指数代理 ETF |

`targets.json` 是目标权重（默认 `74 / 15 / 5 / 6`），`drawdown_policy.json` 是回撤应对档位。两个都可以按自己的风险偏好改。

## 内置的规则体系

### 1. 目标权重与现金下限
默认 **SPYM 74% / QQQM 15% / VXUS 5% / 现金 6%**。

现金 6% 的构成是：整股零头（买整股必须留）+ 全年手续费 + 应急。
**它买的是"不必在最坏时点卖出"的权利，不是收益** —— 现金部分的预期收益按 0 计算。

### 2. 核心宽基只买不卖
不对宽基设止损、不减仓。回撤线（−10% / −15%）只作为**加码刻度**，不产生任何卖出动作。

| SPYM 距 52 周高 | 当月投入 | 现金可降至 |
|---|---|---|
| > −10% | 1× 月额度 | 6% |
| −10% ~ −15% | 1.5× | 5% |
| −15% ~ −25% | 2× | 4% |
| −25% ~ −40% | 3× | 3% |
| < −40% | 退回 1× | 6% |

额外投入从现金缓冲出，**现金见底就只投当月额度，不卖持仓**。

### 3. 个股准入（`eq_gate.py`）
不看账户规模，只看三件事：

```bash
python eq_gate.py NVDA MU
```

1. **装得下**：1 股 ≤ 允许仓位（净值 × 2% ÷ 现实止损，现实止损 = 2.5 × ATR）
2. **赔率 ≥ 2:1**：（52 周高 × 0.97 − 现价）÷ 现实止损
3. **趋势**：价 > MA200 且 MA50 > MA200

第三条是给第二条踩刹车 —— **赔率高的票，往往正是趋势最坏的票**。上行用"回到前高"而不是分析师目标价，因为免费数据源拿不到一致预期。

### 4. 风险贡献（不是资金占比）
```
单一个股风险贡献 = 资金占比 × 该标的 ATR ÷ 组合加权 ATR
```
建议上限：单只 ≤ 25%，全部个股 ≤ 35%。

一个 15% 的纳指仓位，可能占掉组合 24% 的风险 —— **资金占比会骗人，风险占比不会**。

## 输出什么

一份 12 章的 HTML 报告：

```
00 概览       → 净值、当日变动拆解（入金 / 手续费 / 市价）
01 持仓       → 股数、三日对照、目标偏差
02 挂单       → 在途委托、距成交距离
03 触发线     → 关键价位与加码档位
04 走势       → 近 21 个交易日归一化曲线
05 情绪       → 指数、板块、VIX、利率
06 事件       → 当日要闻 + 未来 30 天日历
07 操作指令   → 今天做什么（多数时候是"零"）
08 资金       → 现金拆解、汇率
09 复盘       → 不随行情变动的结论
10 个股准入   → eq_gate 判定表
11 候选池     → 候选标的与回测
```

带封面与目录，锚点跳转，支持 A4 打印分页。

## 数据源

| 用途 | 来源 |
|---|---|
| 报价与历史日线 | `stockanalysis.com`（公开页面 + JSON 端点） |
| 指数、VIX、利率 | CNBC quote API |
| 汇率 | frankfurter（ECB 参考汇率） |
| K 线 | CBOE 延迟行情 |

**没有 API Key，没有付费订阅。** 代价是接口不保证稳定 —— 抓取失败时脚本会保留上一次的数据并打印警告，不会静默产出错数字。

---

## 已知限制

- **不适用于自动化交易**。输出的是给人看的报告，不是下单指令。
- `kline_fetch.py` 的 CBOE 数据**滞后一个交易日**，看当日形态请以报价为准。
- 回测节 `bt_section.py` 未包含在本仓库（依赖 `backtesting.py`），缺失时会自动降级跳过。
- 行情源对同一 URL 有 CDN 缓存，脚本用时间戳破坏缓存；**盘中高频重复请求仍可能拿到旧价**。
- ATR、均线等指标基于日线计算，对跳空缺口不敏感。
